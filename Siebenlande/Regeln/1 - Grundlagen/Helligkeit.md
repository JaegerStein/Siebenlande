Die Helligkeit beeinflusst eure [[Fähigkeiten]] innerhalb und außerhalb des Kampfes.


| Helligkeit   |                                             |                                         |
| ------------ | ------------------------------------------- | --------------------------------------- |
| Gleißend     | Viel zu hell, Blindheit                     | Sicht schlägt automatisch fehl          |
| Blendend     | Zu hell, blendet                            | -4                                      |
| Hell         | Normales Tageslicht                         | 0                                       |
| Düster       | Halbschatten, Dämmerung, reduzierte Sicht   | -4                                      |
| Dunkel       | Fast kein Licht, stark eingeschränkte Sicht | -8                                      |
| Finster      | Gar kein Licht vorhanden, Blindheit         | Sicht schlägt automatisch fehl          |
| Verschleiert | Licht kann nicht durchdringen, Blindheit    | Helligkeit kann nicht verbessert werden |

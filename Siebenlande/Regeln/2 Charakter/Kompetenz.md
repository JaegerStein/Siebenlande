**Kompetenzen** können in [[Fähigkeiten]] und [[Rettungswurf|Rettungswürfe]] je [[Attribute|Attribut]] investiert werden, bis uns was besseres einfällt.

Kompetenz verleiht bei entsprechenden Würfen einen zusätzlichen Würfel entsprechend der Kompetenz-Stufe in dieser Fähigkeit/diesem Attribut:

| Komp. Stufe | 1   | 2   | 3   | 4   | 5   | 6   |
| ----------- | --- | --- | --- | --- | --- | --- |
| Würfel      | W4  | W6  | W8  | W10 | W12 | W20 |
> Wirf man mit dem Kompetenzwürfel die höchste Augenzahl des Würfels (*Kritischer Erfolg*), darf man einen zweiten dazu werfen.

Mehrfache Kritische Erfolge stapeln ist erstmal nicht erlaubt, außer

> [!QUESTION] Wah?
> Ein *Kritisches Versagen* (1) beim gestapelten Kompetenzwürfel löscht den gesamten Kompetenzbonus für diesen Wurf aus. Ein Extrembeispiel (W10 Kompetenz) von grandiosem Glück und desaströsem Pech:
>
> | Wurf | Bonus | Komp. 1 | Komp. 2 | Komp. 3 | Komp. 4 | Ergebnis |
> | :--: | :---: | :-----: | :-----: | :-----: | :-----: | :------: |
> |  10  |  10   |   10    |   10    |   10    |    1    |    20    |
> |  😐  |  😏   |   🙂    |   😀    |   😆    |   😫    |    😞    |

# Kompetenzen Vergeben
Kompetenzpunkte werden ähnlich wie [[Talent|Talente]] in Schritten beim [[Stufen|Stufenaufstieg]] vergeben und können frei investiert werden. Ein Kompetenzpunkt entspricht einer Kompetenzstufe. Man kann alle Kompetenzpunkte in eine Kompetenz setzen.

| Stufe | Kompetenzen | Kumulativ |
| ----- | ----------- | --------- |
| 1     | 2           | 2         |
| 2     |             |           |
| 3     |             |           |
| 4     | 1           | 3         |
| 5     |             |           |
| 6     |             |           |
| 7     |             |           |
| 8     | 2           | 5         |
| 9     |             |           |
| 10    |             |           |
| 11    |             |           |
| 12    | 3           | 8         |
| 13    |             |           |
| 14    |             |           |
| 15    |             |           |
| 16    | 4           | 12        |
| 17    |             |           |
| 18    |             |           |
| 19    |             |           |
| 20    | 5           | 17        |
Auf Stufe 20 hat man also insgesamt 17 Kompetenzen erworben. Das ist genug, um in zwei Fähigkeiten/RW einen zusätzlichen W20 pro Wurf zu erhalten, und zumindest einen W12 auf eine weitere Fähigkeit. Oder man Verteilt sie und erhält einen soliden Bonus auf vielen Gebieten.

# Rechenbeispiele
- Ein Charakter besitzt eine Kompetenz Stufe 3 (W8) für WEI-RW. WEI ist 18, der SG des RW 22:
	  ```1W20 + 8 + 1W8```, z.B. ```12 + 8 + 2 = 22```. Der Charakter besteht den Rettungswurf nur gerade so dank der Kompetenz.
- Ein Charakter versucht sich an einen Gegner anzuschleichen. ATH 21, Kompetenz W10, z.B.:
	  ```2 + 11 + 10 + 9 = 32```

~~**Kompetenz** bedeutet, dass dein Charakter durch seinen Hintergrund in einer [[Fähigkeiten|Fähigkeiten]], einer [[Geübte Waffen|Waffe]], oder einem [[Magie]] besonders geschult ist. Aufgrund dessen versagt der Charakter bei entsprechenden Würfen wesentlich seltener, als die meisten Charaktere.~~

~~*Wenn du bei einem Fähigkeits-, Waffen-, oder Zauberwurf eine 1 wirfst, darfst du einmalig erneut werfen. Das zweite Ergebnis zählt, auch wenn er eine weitere 1 ist. Außerhalb des Kampfes gilt Kompetenz bei jedem entsprechenden Wurf; während des Kampfes kann ein solcher Wurf nur einmalig pro Kompetenz Anwendung finden.*~~
